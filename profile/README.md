## 🚀 Projects

### [CommercialRadar](https://github.com/2026-teecher-summer-team-E/CommercialRadar)
서울 상권(약 1,650개 공식 상권)을 분석해 창업 컨설팅사·프랜차이즈 본사의 입지 의사결정을 돕는 웹 서비스.
서울 열린데이터광장 · 한국부동산원 R-ONE 데이터를 수집해 ETL → PostgreSQL/PostGIS → FastAPI → React로 잇고,
생존율·유동인구·매출을 예측하는 ML 레이어(Darts TFT/DeepAR + LightGBM)를 얹었습니다.

- Backend · Data · ML — https://github.com/2026-teecher-summer-team-E/CommercialRadar
- Frontend — https://github.com/2026-teecher-summer-team-E/CommercialRadar-frontend

## 💻 Tech Stack

**Frontend:** React, TypeScript, Vite, React Router, Kakao Map, Clerk

**Backend:** Python, FastAPI, SQLAlchemy, GeoAlchemy2, Alembic

**ML:** Darts (TFT/DeepAR), LightGBM, PyTorch

**Database:** PostgreSQL, PostGIS, Redis

**DevOps:** Docker, Amazon EC2, GitHub Actions, Caddy

**Monitoring:** Prometheus, Grafana, OpenTelemetry
